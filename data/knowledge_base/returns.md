# Returns Support

## Return Eligibility

Customers may be able to return eligible products according to the applicable return policy.

Return eligibility may depend on the product, purchase date, and condition of the item.

## Start a Return

Customers who want to return a product should contact customer support or use the available return process.

They should provide the relevant order information when requesting a return.

## Return Condition

Returned products may need to be in an acceptable condition and may need to include the original accessories or packaging.

Customers should review the applicable return requirements before sending an item back.

## Return Shipping

Return shipping instructions depend on the order and the applicable return policy.

Customers should follow the provided return instructions and use the recommended shipping method when required.

## Return Status

Customers can contact support to check the status of a return.

They should provide their order or return information so support can locate the request.

## Damaged Product

If a product arrives damaged, customers should contact support as soon as possible and provide the order information and details about the damage.

Photos or other evidence may be requested during the investigation.

## Wrong Product Received

If a customer receives an incorrect product, they should contact support with their order information and explain the issue.

Support will provide instructions for returning the incorrect item and resolving the order.

## Exchange

If an exchange is available for the product, customers should contact support to confirm eligibility and receive the appropriate instructions.
